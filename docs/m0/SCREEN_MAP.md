# RoomGenius 2.0 - Screen Map

## Primary navigation

### Home / My Rooms

- list saved room projects;
- create a project;
- show loading, empty, and failure states;
- resume an existing project.

### Create Room Wizard

1. Room Basics - name, room type, photo, optional dimensions.
2. Design Preferences - style, mood, colors.
3. Constraints & Budget - keep/remove/add items and budget.
4. Review & Create - validate and persist the project.

### Project Overview

The project entry point for the four downstream areas:

- Design Studio;
- Shopping List;
- Budget Tracker;
- Execution Plan.

### Design Studio

- design brief;
- generation entry point;
- saved variants;
- comparison and favorite selection;
- prompt copy as a supporting action.

### Shopping List

- furniture items and quantities;
- user-entered estimates;
- source and checked-at information;
- purchase status.

### Budget Tracker

- estimated cost;
- actual spent;
- forecast total;
- over-budget warning.

### Execution Plan

- project tasks;
- task status and optional due date;
- shopping progress separated from execution progress;
- next actions.

## M0 boundary

M0 documents the target map and verifies the current shell. It does not claim
that every target screen or journey is implemented yet.
